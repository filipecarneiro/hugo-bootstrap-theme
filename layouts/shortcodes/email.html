{{/* Email Shortcode Write an email address split across data attributes, so the plain local-part@domain string never appears in the served HTML. Emits no inline script: main.js upgrades the span to a mailto link, which keeps the shortcode usable under the theme's default script-src 'self'. Without JavaScript the span itself stays readable as "user at domain". Parameters: - "user" local-part of the email address (local-part@domain) - "domain" domain of the email address (local-part@domain) - "class" class or classes to be applied on the element. (default empty) Example: {{< email user="john.smith" domain="example.com" class="cool-link" >}} */}} {{- $user := .Get "user" -}} {{- $domain := .Get "domain" -}} {{ $user }} at {{ $domain }}
